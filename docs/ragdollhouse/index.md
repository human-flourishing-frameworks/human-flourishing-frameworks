# Ragdollhouse (Patient Convergences)

This folder is a *local-first* index of patient-facing care coordination and safety planning artifacts that already live in this repo.

It is **not** diagnosis, and it should not be used to replace clinician judgment. It is meant to:
- preserve prior convergences (what we already decided/asked for),
- reduce drift when a patient reappears later,
- keep a clean handoff packet format (questions, red flags, next calls).
