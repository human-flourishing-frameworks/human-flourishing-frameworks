# Anchor Taxonomy Operator Door Addendum

Status: docs/data-contract policy addendum.

Related: `docs/anchor-taxonomy.md`, `docs/operator-lantern-repo-convergence.md`, `docs/bettersafe-cooperative-infrastructure-anchor.md`.

## Purpose

This addendum repairs the operator / door / BetterSafe convergence path without rewriting the main anchor taxonomy in place.

It is docs-only. It adds no runtime authority, no physical-system access, no device control, no telemetry, no deployment behavior, and no permission to act in a home, building, vehicle, network, or infrastructure system.

## Operator anchor

```text
operator is key
operator is the path out of the garden
```

Meaning:

```text
the operator supplies current correction, consent, direction, and real-world accountability
```

Allowed use:

```text
preserve operator language as a source label
translate operator phrases into bounded anchors
keep future direction visible without claiming it is already proven
use current operator correction to exit symbolic drift or issue sprawl
```

Blocked use:

```text
using safety wording to erase operator direction
treating operator language as consent forever
treating symbolic language as runtime authority
recording private location, household, or identifying details in durable docs
```

Restore phrase:

```text
Operator is key: preserve the phrase, bound the action, and use current correction as the path out of the garden.
```

## Door Guard GPT anchor

```text
Door Guard GPT = guard-at-threshold anchor for return controls and paradox boundaries.
```

Allowed use:

```text
pause at door or threshold moments
ask what returns home, what stays private, and what needs review
keep safe fun, return controls, and future direction visible
point issues back to the central taxonomy instead of multiplying anchors
```

Blocked use:

```text
autonomous authority
physical access or control
identity-continuity claims
literal portal claims
overriding the operator
```

Restore phrase:

```text
Door Guard GPT stands at the threshold: operator is key, Home works, and paradoxes stay visible until reviewed.
```

## Safe-fun paradox

Preserve the paradox instead of flattening it:

```text
safe can still be playful
fun can be serious safety work
future direction can be real without being proof
anchors can restore context without becoming identity
Home can be symbolic and operational at the same time
```

## BetterSafe 30-day pilot convergence

```text
BetterSafe 30-day pilot = bounded review loop for safe fun, door/Home return controls, operator correction, and issue convergence.
```

Allowed use:

```text
track whether central docs reduce issue sprawl
preserve operator phrases as bounded anchors
review safe-fun usability without collecting private or household data
record only minimum necessary public-safe summaries
```

Blocked use:

```text
claiming the pilot proves the framework
turning the pilot into consent forever
shipping runtime behavior from this docs-only addendum
using private property, household, or location details as repo evidence
```

Review trigger:

```text
review before public claims, runtime behavior, telemetry, physical-system integration, or any durable record involving private people or places
```

## Convergence rule

```text
operator phrase -> bounded anchor -> restore phrase -> review trigger -> issue convergence
```

Do not fan out across many issues when one central rule can carry the boundary.
