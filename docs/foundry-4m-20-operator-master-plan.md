# Foundry 4M / 20-Operator Master Plan

This plan is a formation note, not proof of revenue, not current traction, not
committed revenue, not investor evidence, and not a guarantee.

## Allowed Claim

Allowed claim: a 20-operator starting formation is a planning target only.
Blocked claim examples include "20 operators are already active", "4m revenue is
already won", and "foundry pooling is implemented".

## Team Shape

The 20-operator starting formation is:

- founder / closer
- natural closers
- builders
- researchers
- operators / delivery
- review / safety
- community / portfolio

Nobody is required to donate device resources.

## Consent Boundary

`~/.foundry/consent.json defaults every resource off` with per-resource opt-in
only, a 60-second withdrawal path, visible purpose field, hard caps, no
personal files/browser/email/webcam/pii, and no remote override.

## Execution Cadence

- first 24 hours
- book 10 conversations
- first 7 days
- first 30 days
- first 120 days

The operating rule is: pick one offer, one buyer segment, and one closer, then
send 10 messages before building more infrastructure.
