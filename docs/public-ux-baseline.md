# Public UX Baseline

Status: active
Last reviewed: 2026-06-01

## Principles

1. Show the state. Every panel shows current data, not stale cache.
2. Say the limit. If data is incomplete, say so — don't hide gaps.
3. Make the main path easy. The dashboard should be usable without docs.
4. Keep uncertainty visible. Confidence intervals and uncertainty bands stay on.
5. Do not claim translated support until reviewed human copy exists for that language.
