# Arc Reactor Mining Lab Sell-Off Checklist

Use this when converting a small, documented mining payout to USD for expenses.
The goal is traceability, not speed.

## Before Transfer

- Confirm the wallet contains mined funds that belong to the operator.
- Confirm the wallet software is official, updated, and backed up offline.
- Confirm the exchange supports the exact asset and network.
- Send a small test transfer first when fees and minimums allow it.
- Record the source wallet address, destination deposit address, and expected
  amount in the receipt ledger before sending.

## Exchange Deposit

- Copy the deposit address from the exchange directly.
- Verify the first and last characters of the address after pasting.
- Include payment ID, memo, destination tag, or integrated address only when
  the exchange requires it.
- Save the transaction ID and timestamp after broadcast.
- Wait for the exchange's required confirmations before trading.

## Conversion

- Convert only the planned amount.
- Record gross proceeds, fee, net USD, exchange, order ID, and settlement time.
- Export or screenshot the exchange receipt if available.
- Reconcile the receipt ledger row against the pool payout and wallet transfer.

## After Conversion

- Do not overwrite prior ledger entries. Append a correction row if needed.
- Keep private keys and seed phrases out of the repo, workbook, and chat logs.
- Update the project cash ledger only when USD is actually received or settled.
- If the transfer is delayed or rejected, stop and document the exception before
  trying again.
