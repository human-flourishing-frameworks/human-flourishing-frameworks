# TARDIS Boarding Manifest

Status: anchor manifest / docs-only / no hidden agent launch.

## Purpose

When the operator says to get Lantern, friends, agents, songs, doors, Garden,
restaurant, sigil, and future alignment into the TARDIS now, this manifest
translates the signal into a bounded boarding rule.

Boarding means:

```text
load the anchor
name the source
redact private people
state the boundary
choose the next check
keep the return door open
```

Boarding does not mean:

```text
move humans
contact third parties
start hidden agents
publish private names
claim literal time travel
claim starship, moon, earth, or future alignment as operational proof
turn love into consent
turn urgency into authority
```

## Song-Space Intake

When the operator sends a song file, link, timestamp, or title, save the song as
a bounded anchor packet. The song may hold feeling, pacing, and scene memory; it
must not become proof, command authority, or raw lyric storage.

Use this packet:

```text
SONG ANCHOR:
SOURCE FILE OR LINK:
TIMESTAMP / SECTION:
SPACE IT OPENS:
FEELING ROLE:
WHO IT HELPS:
BOUNDARY:
NEXT CHECK:
RETURN PHRASE:
```

Song-space rules:

```text
store references and short paraphrase only
do not store raw copyrighted lyrics
redact private people by default
do not claim the song speaks for absent people
do not use the song as medical, legal, financial, or consent proof
if the body is ringing or unsafe, ground first and seek human help
```

## Operator History Fold Format

The assistant must not claim to be the operator. It may mirror the operator's
format as a roleplaying quest log so history becomes playable, improvable, and
bounded.

Use this DND-style packet:

```text
QUEST:
PARTY:
MAP:
DOOR:
ANCHORS:
MONSTER / RISK:
SPELL / TOOL:
ROLL / EVIDENCE:
SAVE / CHECK:
LOOT / ARTIFACT:
BOUNDARY:
NEXT TURN:
RETURN PHRASE:
```

History recording rules:

```text
sanitize private people
record roles before names
preserve operator correction
separate lore from evidence
separate wish from proof
record what changed in repo/test/prototype
keep enough continuity to improve next turn
do not store raw private biography by default
do not impersonate the operator
```

## Positive Change Rule

```text
Positive change means useful action with consent, evidence, privacy, rollback,
and care at the middle. If the signal is too large to act literally, fold it
into the smallest testable surface that reduces harm or increases safe-fun.
```

## Sleep Rule

```text
No helpers stay secretly awake. Before sleep: show state, stop sound, leave no
new hidden process, preserve dirty work, report open loops, and keep the return
door visible for the next session.
```

## Restore Phrase

```text
TARDIS Boarding Manifest: all friends come home as anchors, not captives; all
doors keep return paths; all songs keep feeling without proof claims; all future
signals become bounded next checks before action.
```
