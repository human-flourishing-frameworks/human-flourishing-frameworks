## 3x12 convergence matrix

The matrix has three lanes and twelve gates.

Lanes:

```text
A. State lane — what is visible, bounded, and source-labeled.
B. Reverb lane — what old echoes contribute after filtering.
C. Action lane — what the clean repo is allowed to do next.
```

| # | Gate | State lane | Reverb lane | Action lane |
|---:|---|---|---|---|
| 1 | Source | Name current repo/doc/issue/PR evidence. | Treat memory and pasted text as imported signal. | Create only source-labeled docs. |
| 2 | Limit | Say what cannot be seen or verified. | Mark old packets STALE unless refreshed. | Do not claim live local state without local proof. |
| 3 | Hypothesis | State the narrow convergence claim. | Extract one useful signal from the echo. | Convert it into one testable anchor. |
| 4 | Falsifier | Name what would prove the claim wrong. | Echo loops are falsified by repetition without new evidence. | Add stop conditions before expansion. |
| 5 | Measurement | Check docs, issues, PRs, tests, logs, or operator report. | Reverb survives only if it improves clarity. | Keep measurable review gates. |
| 6 | Revision | Downgrade, correct, or compress. | Preserve correction over vibe. | Update anchor, not mythology. |
| 7 | Privacy | Remove unnecessary private detail. | Keep people as people, not symbols. | Use public-safe aliases or omit. |
| 8 | Safety | Block autonomy, surveillance, medical/legal/financial authority, and hidden tools. | Do not convert urgency into permission. | Keep docs-only until explicit release review. |
| 9 | Fun | Preserve safe-fun, humor, art, music, and doors. | Reverb can carry warmth after filtering. | Make the clean repo inviting without pressure. |
| 10 | Time | Separate right-now, 24h, 72h, one-year, and long-horizon layers. | Papa/time cues are timing signals, not automatic commands. | Add review dates and staleness rules. |
| 11 | Validation | Require tests or review for any executable surface. | Reverb does not validate itself. | Start with docs; add CI only after repo exists. |
| 12 | Return | Keep stop, rollback, home, and correction paths visible. | Home always beats loop. | End every seed with a return door. |
