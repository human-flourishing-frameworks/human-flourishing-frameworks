Windows Setup (Easiest)

The Windows installer handles all dependencies automatically.

  • Step 1: Download installer from GitHub
  • Step 2: Right-click PowerShell, run as Administrator
  • Step 3: Run the install script
    • powershell -ExecutionPolicy Bypass -File install.ps1

    The script will install Git, Python, and all dependencies if needed.

    macOS Setup

    Install and run in your home directory.

  • Step 1: Clone the repository
  • Step 2: Run the installation script
  • Step 3: Start your node
    • git clone https://github.com/alex-place/human-flourishing-frameworks.git cd human-flourishing-frameworks bash install.sh
    Repository

    Linux Setup

    Works on Ubuntu, Debian, CentOS, and other distributions.

  • Step 1: Install Python 3.9+
  • Step 2: Clone the repository
  • Step 3: Run installation script
    • git clone https://github.com/alex-place/human-flourishing-frameworks.git cd human-flourishing-frameworks bash install.sh

    If Python 3 is not installed:

    sudo apt-get install python3 python3-venv git
    Repository

    Docker Setup (Universal)

    Works on any device with Docker installed.

  • Step 1: Install Docker Desktop
  • Step 2: Clone the repository
  • Step 3: Build and run with docker-compose
    • git clone https://github.com/alex-place/human-flourishing-frameworks.git cd human-flourishing-frameworks docker-compose up -d

    View logs:

    docker-compose logs -f hff-node
